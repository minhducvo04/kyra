# v2 Phase 1 — service boundaries and state (plan, 2026-09-06)

Decisions already made: target AWS (ECS Fargate + RDS Postgres + S3 + SQS, Terraform); slices sized to one
evening each because the interview date is unknown; local-first, so spend starts only at the deploy slice.
Design source: `docs/v2-outline.md` §2 Phase 1.

## Slice 1 — config, error envelope, container — DONE 2026-09-06 (PR #2)
1. `companion/settings.py`: one pydantic-settings `Settings` (API key, data dir, log level, classifier adapter,
   STT model, keybindings, database URL), `.env`-aware, cached via `get_settings()`. Existing env var names
   kept, `config.require_api_key()` kept as a thin wrapper. -> verify: `pytest`; `KYRA_DATA_DIR` override still
   isolates tests; `.env` still loads the key.
2. `companion/errors.py`: `ApiError` + handler -> `{"error": {"code", "message", "details"}}` with real 4xx/5xx.
   Migrate the 7 `return {"error": ...}` endpoints and the 2 JS readers; a shared `readJson()` in app.js throws
   the envelope message so every fetch path shows the server's reason. -> verify: TestClient asserts status codes;
   real browser click-through of an invalid tracker status and a bad backend name.
3. `Dockerfile` (python:3.12-slim, web-only requirements: no torch/mlx/voice - those stay on the Mac),
   `docker-compose.yml` (api + postgres, postgres unused until slice 2), `.dockerignore`, CI job that builds the
   image. -> verify: CI `docker build` green (Docker isn't installed locally); container starts and `GET /` serves.
4. Record: CLAUDE.md commands + decisions; `industry-standards.md` error-envelope row -> done.

## Slice 2 — Postgres behind the store interfaces — DONE 2026-09-06
SQLAlchemy Core + Alembic; `RemindersStore`, `LearningStore`, `JobApplicationStore`, `JobDocumentStore` get a
Postgres backend selected by `DATABASE_URL`; SQLite stays the default. -> verify: the existing store tests run
against both backends (parametrized), compose `postgres` service.

## Slice 3 — jobs and streaming
Queue (SQS locally via LocalStack or Redis) for the resume fit loop; SSE progress; sandboxed LaTeX container.

## Slice 4 — deploy
Terraform: ECS Fargate service, RDS Postgres, S3 for PDFs, SQS, Secrets Manager, CloudWatch. Tear-down script.

## Not in Phase 1
Auth/OIDC (needed before any second user or the visionOS client), Chroma -> pgvector, prompt caching.
