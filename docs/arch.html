Everything

How Kyra fits together. A private box holds the owner, their data and the private code; none of it is in this repository. The owner talks through voice or text to a turn router that answers with local models, and with hosted models outside only when a release label allows it. A feature request is planned, built by agent lanes, then tested and landed: it is either landed on master or refused with nothing merged. Memory gives the router and the lanes context packs and takes inbox lines back. The CAD kernel builds GLB files that the owner opens in the 3D viewer.
